Yalding Taxis website

Open index.html in a browser to preview the site.

The airport fare finder contains 108 pickup villages from Book1.xlsx.
4-seat fares are the source/base prices. The website adds £20 for a 6-seat people carrier and £40 for an 8-seat minibus.
Prices are presented as one-way and inclusive of airport pickup/drop-off charges and applicable tolls, with confirmation requested when booking.

Main files:
- index.html
- assets/ (website images)
- assets/airport-fares-4-seat.csv (maintenance copy of the base fare data)

The site is static and suitable for GitHub Pages or similar static hosting.
